# iQOO 12 setup

Copy deliverables/SmartTrack-debug.apk to the phone and install it. Join the laptop JAY hotspot in 2.4 GHz mode. Run START_SMARTTRACK.cmd on the laptop, then SHOW_LOGIN.cmd for the account. Use http://192.168.137.1:8080 in SmartTrack. Select the wearable and open Temperature. See [full instructions](docs/WIFI_SETUP.md).
